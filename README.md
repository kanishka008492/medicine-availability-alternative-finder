# Medicine Availability and Alternative Finder

## Project Better Tomorrow – Semester 3

### Problem Statement
People often face difficulty finding required medicines at nearby pharmacies. 
When a medicine is unavailable, they may need to visit multiple pharmacies, 
which wastes time and can be difficult during urgent situations.

### Proposed Solution
Medicine Availability and Alternative Finder is a simple web application that 
helps users search for a medicine, check its availability, and view possible 
alternatives when the required medicine is unavailable.

### Main Features
- Search for medicines by name
- Check medicine availability
- Display pharmacy details
- Show possible medicine alternatives
- Provide safety guidance for alternatives
- Simple and user-friendly interface

### Technologies Used
- HTML
- CSS
- JavaScript
- AI-assisted ideation

### Project Status
🚧 Project under development – Review 1 (35% Completion)

### Safety Notice
This project is an educational prototype. Alternative medicine information is 
for informational purposes only. Users should consult a qualified doctor or 
pharmacist before changing or replacing any prescribed medicine.
